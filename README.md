# 🤖 AI Lab: Tri-Agent Collaborative Development System

Welcome to the **AI Lab** workflow system. This workspace is configured for an orchestrated 3-agent development lifecycle where specialized AI roles collaborate seamlessly to design, implement, and verify high-quality software.

---

### 1. Leader & Prompt Architect (Antigravity)
* **Role**: Technical Lead, System Architect, Prompt Engineer.
* **Responsibilities**:
  * Breaks down product requirements into actionable engineering tasks.
  * Writes comprehensive, unambiguous task prompts for the Programmer.
  * Coordinates handoffs, monitors quality gates, and grants final approval.
* **Prompt Reference**: [`prompts/LEADER_PROMPT.md`](file:///s:/ailab/prompts/LEADER_PROMPT.md)

### 2. The Programmer (ChatGPT / Codex)
* **Role**: Software Engineer / Code Implementer.
* **Responsibilities**:
  * Reads the prompt specification created by the Leader in `tasks/active/`.
  * Implements clean, modular, type-safe, and well-documented code.
  * Writes unit tests and documents implementation decisions.
* **Prompt Reference**: [`prompts/PROGRAMMER_PROMPT.md`](file:///s:/ailab/prompts/PROGRAMMER_PROMPT.md)

### 3. The Double Checker (OpenCode)
* **Role**: Code Reviewer, Quality Assurance, Security Auditor.
* **Responsibilities**:
  * Reads the code generated by the Programmer.
  * Checks for logical errors, syntax issues, edge cases, vulnerabilities, and efficiency bottlenecks.
  * Runs automated audits via the OpenCode CLI and fills in the Double Checker section in the task file.
* **Prompt Reference**: [`prompts/CHECKER_PROMPT.md`](file:///s:/ailab/prompts/CHECKER_PROMPT.md)

## ⚡ Using OpenCode CLI

OpenCode is installed on this system. On Windows PowerShell, use `opencode.cmd` directly (or execute with `-ExecutionPolicy Bypass` if calling PowerShell wrappers):

1. **Interactive TUI**:
   ```powershell
   opencode.cmd
   ```
2. **Headless Code Review with a specific prompt**:
   ```powershell
   opencode.cmd run --file "src/fire_safety/index.html" "Review this code for edge cases and potential bugs."
   ```
3. **Using the AI Lab Helper Script**:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\review.ps1 -TargetFile "src/fire_safety/index.html" -TaskFile "tasks/active/TASK-002-fire-safety-guide.md"
   ```

## 🔄 Step-by-Step Task Workflow

1. **Step 1 (Leader)**: Antigravity copies `tasks/TEMPLATE.md` to `tasks/active/TASK-XXX.md`, fills out the specifications, acceptance criteria, and programmer prompt.
2. **Step 2 (Programmer)**: ChatGPT / Codex reads the prompt, writes the code into `src/` and tests into `tests/`, and notes any details in the task file.
3. **Step 3 (Double Checker)**: OpenCode reviews the implementation against the acceptance criteria, runs/checks tests, and logs findings.
4. **Step 4 (Leader)**: Antigravity reviews OpenCode's findings. If fixes are needed, steps 2 & 3 repeat. Once verified, the task is moved to `tasks/completed/`.
